# Machine Learning Visualizer

A passion project to help teach people about Machine Learning Concepts such as Linear Regression, Random Forests and Random Forests in an interesting and interactive way!

**Here's a link!**: https://michael-v-b.github.io/ML-Visualizer/

## How's it made?

This website uses:

- Vite as a base (chosen for speedy implementation of boilerplate code)
- React Framework (chosen for expandability and allows for an Object Oriented Approach to Development)
- Coded in Typescript (this allows for an organized structure for code, preventing simple mistakes)
- Styled in CSS
- And Rive to construct the SVG graphics

## Structural Decisions

Each page is implemented using a custom framework which has elements for the Title and Sidebar.
Additionally, each informational page features only a single image which changes as a different line of text reaches the center of the screen to promote efficiency.
Furthermore each image is an SVG animation which allows for scalability and clarity for different screen sizes.
